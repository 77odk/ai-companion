# 忆文 Eluvin · AI 伴侣

> 一个会记得你、和你一起积累时间的养成型 AI 伴侣。
> 忆过往，成文思 —— 记得住你，也帮得上你。

在线体验：[eluvin.space](https://eluvin.space)（国内可直接访问）

## 这是什么

忆文不是又一个聊天 Demo，也不是把一堆工具塞进对话框里的 AI 助手。

TA 是「一个有自己日子在过、也会和你一起留下时间的人」：

- **TA 记得住你**：你说过的话、你的喜好和重要信息，会沉淀成长期记忆
- **TA 有自己的生活**：会发动态、会有「此刻」状态，也会在周记里回响这一周
- **你们有共同经历**：约好的事、一起经历过的事件和重要节点，会沿着真实时间继续往后走
- **TA 有连续的时间**：认识第几天、纪念日、当前时间等由程序维护，不靠模型随口编
- **TA 不会替你编过去**：只把真实发生过、能够追溯的内容当作共同记忆，并专门约束「编造共同经历」

现在的产品主线围绕 **一个 TA 的长期关系** 展开；多角色能力仍然保留，但作为进阶能力而不是默认主流程。

技术上的核心判断一直没变：**模型负责理解和表达，程序负责事实、状态与确定性逻辑。**

## 功能

- **长期记忆**：显式记忆与自动提取分开管理，支持主题归拢、编辑与来源追溯
- **关系与时间**：认识天数、纪念日、重要节点与时间上下文保持连续
- **一起经历过**：共同事件独立沉淀，不再只是把普通记忆按日期拼在一起
- **TA 的空间**：动态、时间轴、周记、照片墙等共同组成 TA 持续发生的生活
- **生活因果链**：聊天里约好的事 → TA 记住时间 → 到那天产生呼应 → 后续聊天与周记继续承接
- **TA 此刻**：状态、时间与环境信息有真实上下文约束，减少模型凭空发挥
- **内心戏**：思考模型的推理过程收进「TA 想了想」灰条，点开再看，正文与 thinking 分离
- **忙碌状态**：TA 可以进入忙碌状态，过一段时间再自然回来继续话题
- **英文模式**：语言作为系统级变量贯穿人设、记忆、空间与聊天
- **多设备同步**：登录账号后，聊天、记忆、角色与空间数据可跨设备同步
- **多角色（进阶）**：不同 TA 保持各自的人设、会话与聊天中沉淀的记忆隔离；显式「关于我」记忆可跨角色共享

## 架构要点

- 客户端为主的 PWA：**React 18 + TypeScript + Vite + PWA**
- **用户自带模型 API Key**：模型请求由浏览器直连兼容接口，平台不托管用户模型 Key
- 本地优先：记忆、状态、会话与时间线优先保存在客户端，并通过账号进行云端同步
- 独立后端（不在本仓库）：负责账号、同步以及必要的服务端能力；模型调用本身不依赖平台算力
- 角色边界：会话、聊天中沉淀的记忆与状态按角色隔离；显式「关于我」记忆可跨角色共享
- 提示词与模型调用分层：`chatPrompts.ts`（话语层）/ `modelChat.ts`（调用层）
- 事实约束优先于生成自由：共同经历、时间、关系状态等由可验证数据驱动，而不是只靠提示词约束

## 本地运行

```bash
npm install

npm run build    # tsc + vite + PWA + 构建指纹（不做代码混淆）
npm run lint     # 静态检查
```
