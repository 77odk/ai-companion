# 忆文 Eluvin · AI 伴侣

> 一个会记得你、和你一起积累时间的养成型 AI 伴侣。
> 忆过往，成文思 —— 记得住你，也帮得上你。

在线体验：[eluvin.space](https://eluvin.space)（国内可直接访问）

## 这是什么

忆文不是又一个聊天 Demo。

TA 会记得你说过的话，也有自己的生活、时间和与你共同经历过的事情。产品主线围绕 **一个 TA 的长期关系** 展开，多角色作为进阶能力保留。

技术上的核心判断是：**模型负责理解和表达，程序负责事实、状态与确定性逻辑。**

## 基础功能

- **聊天**：和 TA 持续对话，支持流式回复与思考内容分离
- **长期记忆**：记住你的重要信息、偏好和聊天里值得留下的内容
- **TA 的空间**：动态、时间轴、周记、照片墙等内容会随着相处持续积累
- **关系与时间**：认识天数、纪念日和重要节点保持连续
- **一起经历过**：记录你和 TA 真实发生过的共同事件
- **TA 此刻**：根据时间与上下文呈现 TA 当前的状态
- **忙碌状态**：TA 可以暂时去忙，之后再自然回来继续话题
- **英文模式**：支持英文聊天与相关内容
- **多设备同步**：登录后可同步聊天、记忆、角色与空间数据
- **多角色（进阶）**：可创建不同 TA，并保持各自的会话与角色内容

## 技术

- React 18 + TypeScript + Vite + PWA
- 用户自带模型 API Key，模型请求由浏览器直连兼容接口
- 客户端本地优先，并通过独立后端完成账号与云同步
- 本仓库主要为前端代码，后端独立部署
