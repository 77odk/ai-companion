# 空间页 3D：视觉完善

本批承接 feat/space-3d-phase1，完善已批准的构图、材质、光照与书页呈现；不做摆件拖动或持久化。原 2D 页面、入口回调、数据链路、天气缓存、受保护模块与依赖锁文件保持不变。

## 变化

- 总览把视线下移到桌面，增加俯视角度并给左窗留出空间；阅读仍保证当前页约 300 CSS px，抽屉机位沿用既有导轨状态。
- 木纹改为细长纤维，墙与亚麻降低色彩噪声；地板独立使用暖色程序纹理及不同种子、粗糙度、法线。
- 1024×512 的程序化间接反射源只生成一次，不含太阳、阴影或移动摆件。PMREM 在场景初始化时转换，玻璃与陶瓷有环境反射，夜间反射强度降低。没有新增投影光源、运行时路径追踪或常开后处理。
- 玻璃中心透明、边缘按视角增强反射；罐子补真实陶瓷底。台灯罩可见暖色发光，仍由原 SpotLight 负责夜间投影。
- 左窗后方有不投影的天空平面，颜色随环境过渡；窗洞实体与太阳遮挡规则不变。
- 无照片时不再渲染空卡片网格，有照片时仍显示原有图像、保持比例；照片入口不变。
- 书增加实体书脊，纸面加强留白、墨色与极轻的装订边渐变。分页、消息 ID 与偏移、DOM 阅读功能均不变。
- 控制条减少视觉重量，文案、按钮作用与点击转发不变。

## 新纹理色彩空间

| 来源 | 尺寸 | 色彩空间 |
| --- | --- | --- |
| floor color | 512²，可重复 | SRGBColorSpace |
| floor roughness / normal | 512²，可重复 | NoColorSpace |
| reflectionCanvas | 1024×512 | CanvasTexture 输入 SRGBColorSpace；PMREM 输出线性渲染目标 |

固定桌体、墙、窗洞和地板几何尺寸未变，原 AO / lightMap 文件保持原样。反射源是低频间接环境，不烘焙太阳或摆件投影。

## 验证与限制

沿用 scripts/screenshot_space3d.mjs 的固定日期、天气、DPR、三机位和三尺寸，基准图须经查看后更新。scripts/test_*.mjs 的全部原有断言不改。npm test 实测 270 pass / 0 fail；npx tsc -b、npm run build 均通过。运行时复验包含三种故障回落及五入口、完整四级阶梯、静止停渲染、DOM 搜索/字号/位置、夜间与背向窗照明、布置骨架无内容写入。

三机位 × 390×844 / 360×800 / 1280×800 的九张最终截图已更新并复拍，SHA-256 全部一致，0 页面错误、0 横向溢出；阅读投影页宽保持 280–320 CSS px。

软件渲染场景/整页 fps：390×844 为 1.81/1.81，1280×800 为 0.66/0.66，实际 AISpace 的 390×844 为 2.03/2.03；详见 space3d-validation/runtime.json。单帧可能超过原诊断的 1200ms 计时，因此静止测量前增加双 rAF 排空待绘制帧，静止断言及 scripts/test_*.mjs 全部原断言不变。

软件渲染只用于功能与视觉核对，不替代真机或 6× CPU 降档模拟。阴影、DPR、粒子及最终 2D 回落阶梯保持启用；PMREM 的初始化成本需由手机验收进一步核对。

最大内容单独复验：8 张照片、48 颗星、5 封信、200 雨粒子、1024 阴影、DPR1，实测 99 draw calls / 27426 triangles，0 shader / 页面错误，详见 space3d-validation/polish-budget.json。照片板减少一项收益较小的投影，给天气雾幕保留 1 call 余量；窗墙和桌面动态遮挡不变。
