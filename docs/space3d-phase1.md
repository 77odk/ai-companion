# 空间页 3D 化 · 第一批

基线：sandbox `01bd2205afaff7db08c7480bc243062b8c0fe9bd`。不合并、不部署。

## A 组

`environment.ts` 只接收 UTC 时间与设定城市坐标/IANA 时区；按 NOAA fractional-year 简化公式计算太阳方位与高度。方位 clockwise from north，窗口朝外法线默认 165°。日夜由太阳高度决定，Open-Meteo 的 isday/sunrise/sunset 保留为天气元数据，不用来覆盖太阳几何。

数据缺少城市时区时不启用新反馈，绝不使用设备时区代替。旧天气缓存仍可用，保持 30 分钟有效期、同一 consent key 与同一 queryCity 校验。新字段在正常到期请求时补齐，不强制刷新旧缓存。

2D 反馈默认关闭，开启后仅叠加最多 2.5% 的灰/冷色；三张首页原图与既有阴天图逻辑不变。视图偏好与阅读位置共用已有 `ai_companion_settings` 中的 `spaceEnvironment` 字段，模型设置保存时保留它，不写聊天/记忆/照片。

基线 npm test：137 pass / 0 fail（Node 24.19.0）；不是 AGENTS.md 的历史数字。

## 已批准的裁决

- 书页统一 1024×2048，纹理有效区域按真实页面比例映射，不能拉伸。
- 总览双页；阅读机位当前页目标宽 280–320 CSS px，长记录用 DOM。
- 布置模式保留进入/退出、选中、机位和仲裁，本批不拖动物件、不保存摆放。
- 性能来源分为真实设备、6× CPU/机型模拟、无头软件渲染。真机由七七验收，模拟由项目方提供，不能填成已测。
- 三机位×三尺寸截图固定时间、天气、DPR，脚本与基准图入库。
