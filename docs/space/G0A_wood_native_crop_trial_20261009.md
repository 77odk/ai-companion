# Space V2 · G0-A 原生桌面局部补纹试绘（2026-10-09）

## 已找到并用于试验的原生素材

参见 `docs/space/G0A_native_reference_recovery_20261009.md`。本试验从此前保存的 941×1672 原生 PNG《金色时光里的温馨书桌抽屉.png》按图面绝对坐标 `(x0=0,y0=945,x1=941,y1=1672)` 裁取桌面及抽屉区域，得到 941×727 原像素裁切。其源图尚非确认存在可编辑图层的母版；不与之前的 864×1536 JPEG 重采样背景混称“原生 2x”。

## 试绘方法

**不使用之前失败的整套新桌子生成稿**。仅对此原生裁切做 2×图幅试绘，用原始像素保留桌沿、书页、抽屉和信件几何；将低幅度的方向性木纹微细节加在原有桌体表面，不改变物件定位/投影结构：

- 输出：`1882×1454` WebP，163,832 bytes（**交付于独立候选文件，不在 GitHub public 目录**）。
- 源坐标保持不变：输出像素 `x'=2x,y'=2y`，不存在重新设计的抽屉把手/木柜外壳。
- 将试验图降回 941×727 后，与源图像素差的平均绝对值（RGB 全通道）为 **1.45 / 255**。此指标仅证实宏观画面变化小；不能证明高频木纹真是摄影/原稿细节。
- 试绘来源是原生 941×1672 RGB 图，但 2×新细节是**人工合成微纹理**，不是从图中恢复了真正的 1882×1454 原生细节。

## A/B 视觉评估

**限定结论：几何保留可接受，材质细节增益有限，整体视觉高清门禁仍未通过。**

相比第一次错误的「换一张新桌子」，此方法无新增家具、无圆形把手，桌沿/抽屉缝隙没有发生重构。微纹理幅度保守，肉眼差异细微，还不能解决最大问题——被书、罐、播放器等遮挡的木桌区域没有原生绘制内容。更不能由此冒充 ≥1170×2079 的**无遮挡**原生高清底图。
